# 25 — Remainder / Modulo Operator (%)

## Concept
The `%` operator returns the remainder left over when one operand is divided by a second operand.

## Syntax
```javascript
export function modulo(a, b) {
  return a % b;
}
```

## Quick Example
```javascript
7 % 3; // 1
```

## Task
Export a function `modulo(a, b)` that returns `a % b`.
