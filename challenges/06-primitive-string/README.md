# 06 — String Primitive

## Concept
Strings represent textual data and are wrapped in quotes (e.g. `"hello"` or `'world'`).

## Syntax
```javascript
export const str = "text";
```

## Quick Example
```javascript
export const greeting = "Welcome!";
```

## Task
Export a constant named `str` with any non-empty string value.
