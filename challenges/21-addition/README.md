# 21 — Addition Operator (+)

## Concept
The `+` operator adds two numbers together (`a + b`).

## Syntax
```javascript
export function add(a, b) {
  return a + b;
}
```

## Quick Example
```javascript
10 + 20; // 30
```

## Task
Export a function `add(a, b)` that returns the sum of `a` and `b`.
