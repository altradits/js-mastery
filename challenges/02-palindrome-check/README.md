# 02 - Palindrome Check

## Objective
Write a function `isPalindrome(str)` that checks whether a string reads identically forward and backward.

## Constraints & Edge Cases
- Ignore non-alphanumeric characters (spaces, punctuation).
- Case-insensitive ('A' === 'a').
- Use the two-pointer approach for optimal auxiliary space.
- Target Time: O(n) | Auxiliary Space: O(1) (after normalization)
