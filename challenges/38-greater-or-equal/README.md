# 38 — Greater Than or Equal (>=)

## Concept
The `>=` operator returns `true` if the left operand is greater than or equal to the right operand.

## Syntax
```javascript
export function isGreaterOrEqual(a, b) {
  return a >= b;
}
```

## Quick Example
```javascript
5 >= 5; // true
```

## Task
Export a function `isGreaterOrEqual(a, b)` returning `a >= b`.
