# 19 — Increment Function

## Concept
Adding `1` to a number computes its increment (`n + 1`).

## Syntax
```javascript
export function more(n) {
  return n + 1;
}
```

## Quick Example
```javascript
export function next(x) {
  return x + 1;
}
```

## Task
Export a function `more(n)` that returns `n + 1`.
