# 114 — Math.abs Function

## Concept
`Math.abs(x)` returns the non-negative absolute value of a number.

## Syntax
```javascript
export function absolute(n) {
  return Math.abs(n);
}
```

## Quick Example
```javascript
Math.abs(-42); // 42
```

## Task
Export a function `absolute(n)` that returns `Math.abs(n)`.
