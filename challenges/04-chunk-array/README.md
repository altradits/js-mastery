# 04 - Chunk Array

## Objective
Write a function `chunkArray(arr, size)` that splits an array into subarrays of maximum length `size`.

## Constraints & Edge Cases
- Final chunk may contain fewer elements if array cannot be divided evenly.
- Return `[]` if `size <= 0` or input array is empty.
- Target Time: O(n) | Auxiliary Space: O(n)
