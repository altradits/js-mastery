# 26 — Exponentiation Operator (**)

## Concept
The `**` operator raises the first operand to the power of the second operand (`base ** exponent`).

## Syntax
```javascript
export function power(base, exp) {
  return base ** exp;
}
```

## Quick Example
```javascript
2 ** 3; // 8
```

## Task
Export a function `power(base, exp)` that returns `base ** exp`.
