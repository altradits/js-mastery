# 22 — Subtraction Operator (-)

## Concept
The `-` operator subtracts the second number from the first (`a - b`).

## Syntax
```javascript
export function sub(a, b) {
  return a - b;
}
```

## Quick Example
```javascript
20 - 5; // 15
```

## Task
Export a function `sub(a, b)` that returns `a - b`.
