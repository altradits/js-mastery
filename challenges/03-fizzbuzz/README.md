# 03 - FizzBuzz

## Objective
Write a function `fizzBuzz(n)` returning an array from `1` to `n`:
- Multiples of 3 & 5 -> `"FizzBuzz"`
- Multiples of 3 -> `"Fizz"`
- Multiples of 5 -> `"Buzz"`
- Others -> the integer itself

## Constraints & Edge Cases
- Return `[]` for `n <= 0`.
- Target Time: O(n) | Auxiliary Space: O(n)
