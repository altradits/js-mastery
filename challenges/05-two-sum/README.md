# 05 - Two Sum

## Objective
Write a function `twoSum(nums, target)` that returns the zero-based indices of two numbers that add up to `target`.

## Constraints & Edge Cases
- You must achieve O(n) time complexity using a Hash Map (`Map` or object lookup), not O(n^2) nested loops.
- Return `[]` if no valid pair exists.
- Target Time: O(n) | Auxiliary Space: O(n)
