# 01 - Reverse String

## Objective
Write a function `reverseString(str)` that takes a string and returns it reversed without using `Array.prototype.reverse()`.

## Constraints & Edge Cases
- Do not use built-in `.reverse()`.
- Handle empty strings `""` and single characters.
- Maintain character case.
- Target Time: O(n) | Auxiliary Space: O(n)
