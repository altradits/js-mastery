# 48 — Object Initializer Syntax

## Concept
Objects store key-value pairs wrapped in curly braces `{ key: value }`.

## Syntax
```javascript
export const user = {
  name: "Alice",
  age: 25
};
```

## Quick Example
```javascript
const book = { title: "JS", pages: 300 };
```

## Task
Export a constant `user` with properties `name: "Alice"` and `age: 25`.
