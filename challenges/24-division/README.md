# 24 — Division Operator (/)

## Concept
The `/` operator produces the quotient of its operands (`a / b`).

## Syntax
```javascript
export function divide(a, b) {
  return a / b;
}
```

## Quick Example
```javascript
20 / 4; // 5
```

## Task
Export a function `divide(a, b)` that returns `a / b`.
