# 82 — Lowercase Transformation (.toLowerCase())

## Concept
`str.toLowerCase()` returns the string converted to lowercase letters.

## Syntax
```javascript
export function whisper(str) {
  return str.toLowerCase();
}
```

## Quick Example
```javascript
"HELLO".toLowerCase(); // "hello"
```

## Task
Export a function `whisper(str)` that returns `str.toLowerCase()`.
