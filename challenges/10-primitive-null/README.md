# 10 — Null Primitive

## Concept
`null` represents the intentional absence of any object value.

## Syntax
```javascript
export const nullVal = null;
```

## Quick Example
```javascript
export const user = null;
```

## Task
Export a constant named `nullVal` with the value `null`.
