# 36 — Greater Than Operator (>)

## Concept
The `>` operator returns `true` if the left operand is strictly greater than the right operand.

## Syntax
```javascript
export function isGreater(a, b) {
  return a > b;
}
```

## Quick Example
```javascript
10 > 5; // true
```

## Task
Export a function `isGreater(a, b)` returning `a > b`.
