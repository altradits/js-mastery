# 08 — Boolean Primitive

## Concept
Booleans represent logical truth values: either `true` or `false`.

## Syntax
```javascript
export const bool = true;
```

## Quick Example
```javascript
export const isReady = true;
```

## Task
Export a constant named `bool` with the boolean value `true`.
