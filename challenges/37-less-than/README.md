# 37 — Less Than Operator (<)

## Concept
The `<` operator returns `true` if the left operand is strictly less than the right operand.

## Syntax
```javascript
export function isLess(a, b) {
  return a < b;
}
```

## Quick Example
```javascript
3 < 7; // true
```

## Task
Export a function `isLess(a, b)` returning `a < b`.
