# 150 — Bitwise AND Operator (&)

## Concept
`a & b` performs a bitwise AND operation on each pair of corresponding bits (1 if both bits are 1).

## Syntax
```javascript
export function bitwiseAnd(a, b) {
  return a & b;
}
```

## Quick Example
```javascript
5 & 1; // 1
```

## Task
Export a function `bitwiseAnd(a, b)` returning `a & b`.
