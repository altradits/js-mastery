# 20 — Decrement Function

## Concept
Subtracting `1` from a number computes its decrement (`n - 1`).

## Syntax
```javascript
export function less(n) {
  return n - 1;
}
```

## Quick Example
```javascript
export function prev(x) {
  return x - 1;
}
```

## Task
Export a function `less(n)` that returns `n - 1`.
