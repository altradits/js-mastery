# 152 — Bitwise XOR Operator (^)

## Concept
`a ^ b` performs a bitwise XOR (1 if bits are different, 0 if identical).

## Syntax
```javascript
export function bitwiseXor(a, b) {
  return a ^ b;
}
```

## Quick Example
```javascript
5 ^ 1; // 4
```

## Task
Export a function `bitwiseXor(a, b)` returning `a ^ b`.
