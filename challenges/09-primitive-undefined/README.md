# 09 — Undefined Primitive

## Concept
`undefined` indicates the absence of an assigned value.

## Syntax
```javascript
export const undef = undefined;
```

## Quick Example
```javascript
export const empty = undefined;
```

## Task
Export a constant named `undef` with the value `undefined`.
