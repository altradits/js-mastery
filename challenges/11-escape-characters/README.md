# 11 — Escape Characters in Strings

## Concept
Backslash `\` escapes special characters in strings (e.g. `\"` for quotes, `\n` for newlines).

## Syntax
```javascript
export const escapeStr = "`\\\"/'";
```

## Quick Example
```javascript
export const quoted = "She said \"Hello\"";
```

## Task
Export a constant named `escapeStr` containing: backtick, backslash, double quote, forward slash, and single quote: `` `\"/' ``
