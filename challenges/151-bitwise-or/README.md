# 151 — Bitwise OR Operator (|)

## Concept
`a | b` performs a bitwise OR operation on each pair of corresponding bits (1 if either bit is 1).

## Syntax
```javascript
export function bitwiseOr(a, b) {
  return a | b;
}
```

## Quick Example
```javascript
5 | 2; // 7
```

## Task
Export a function `bitwiseOr(a, b)` returning `a | b`.
