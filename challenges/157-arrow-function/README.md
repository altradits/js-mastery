# 157 — Arrow Functions

## Concept
Arrow functions `(a, b) => a + b` provide a compact syntax for function expressions.

## Syntax
```javascript
export const addNumbers = (a, b) => a + b;
```

## Quick Example
```javascript
const multiply = (x, y) => x * y;
```

## Task
Export an arrow function `addNumbers = (a, b) => a + b`.
