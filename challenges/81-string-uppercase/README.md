# 81 — Uppercase Transformation (.toUpperCase())

## Concept
`str.toUpperCase()` returns the string converted to uppercase letters.

## Syntax
```javascript
export function yell(str) {
  return str.toUpperCase();
}
```

## Quick Example
```javascript
"hello".toUpperCase(); // "HELLO"
```

## Task
Export a function `yell(str)` that returns `str.toUpperCase()`.
