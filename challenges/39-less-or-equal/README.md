# 39 — Less Than or Equal (<=)

## Concept
The `<=` operator returns `true` if the left operand is less than or equal to the right operand.

## Syntax
```javascript
export function isLessOrEqual(a, b) {
  return a <= b;
}
```

## Quick Example
```javascript
4 <= 5; // true
```

## Task
Export a function `isLessOrEqual(a, b)` returning `a <= b`.
