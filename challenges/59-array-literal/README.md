# 59 — Array Initializer Syntax

## Concept
Arrays are ordered lists of values wrapped in brackets `[element1, element2]`.

## Syntax
```javascript
export const numbers = [1, 2, 3];
```

## Quick Example
```javascript
const colors = ["red", "blue"];
```

## Task
Export a constant named `numbers` containing the array `[1, 2, 3]`.
