# 07 - Deep Flatten

## Objective
Write a function `deepFlatten(arr)` that recursively flattens an arbitrarily nested multi-dimensional array into a single 1D array.

## Constraints & Edge Cases
- Do not use `Array.prototype.flat(Infinity)`.
- Use recursion and `Array.isArray()`.
- Target Time: O(n) | Auxiliary Space: O(d) recursion stack depth
