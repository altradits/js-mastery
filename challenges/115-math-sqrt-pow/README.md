# 115 — Math.sqrt & Math.pow

## Concept
`Math.sqrt(x)` returns the square root of $x$; `Math.pow(base, exp)` computes powers.

## Syntax
```javascript
export function squareRoot(n) {
  return Math.sqrt(n);
}
```

## Quick Example
```javascript
Math.sqrt(16); // 4
```

## Task
Export a function `squareRoot(n)` that returns `Math.sqrt(n)`.
