# 23 — Multiplication Operator (*)

## Concept
The `*` operator multiplies two numbers together (`a * b`).

## Syntax
```javascript
export function multiply(a, b) {
  return a * b;
}
```

## Quick Example
```javascript
4 * 5; // 20
```

## Task
Export a function `multiply(a, b)` that returns `a * b`.
