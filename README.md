## 🎮 Two Ways to Practice

### Mode 1: The "Code Royale" Web Application (Browser Experience)

Experience JavaScript coding as a sudden-death competitive esports arena!

- 🔥 **Sequential "Piscine Gauntlet" (Beginner to Master)**: Practice from Challenge #01 (`01-constant-variable`) through #216 in strict sequence against adaptive rival coders with sudden-death timers and coin bounties.
- ⚔️ **8-Player Battle Royale**: 8 developers enter, 3 elimination rounds, and the last programmer standing claims the 8x jackpot pot.
- 🎯 **1v1 High-Stakes Duel**: Sudden-death head-to-head match where the fastest coder to pass assertions wins double stakes.
- 🗺️ **Interactive 216-Level Curriculum Map**: Browse all 8 learning modules, track unlocked/completed levels, and jump directly into any challenge.
- 👤 **Persistent Player Profiles & Accounts**: Choose your hacker avatar, track MMR, coin balances, and level progression in `localStorage`.
- 🛡️ **In-Browser Safe Sandbox**: Real-time evaluation of ES Module code with loop timeout protection and virtual assertion console.
- 🔊 **Procedural Web Audio Engine**: Zero-dependency audio synthesizer generating real-time countdown ticks, coin clinks, elimination drops, and victory fanfares.

---

### Mode 2: High-Velocity Terminal CLI (VS Code / Terminal)

A focused, zero-clutter terminal drill environment:

```bash
# 1. Step-by-step interactive drill runner (shows passed badges + clean PASS/FAIL):
npm start
# or: npm run drill

# 2. Live auto-detecting watch mode (re-tests automatically on Cmd + S):
npm run watch

# 3. Test current active challenge:
npm test
# or: npm run current

# 4. Launch local web server:
npm run app
# or: npm run serve

# 5. Reset all 216 challenge files to starter comment stubs:
npm run reset
```
