# JS Mastery: The Complete JavaScript Piscine Practice Engine

An interactive, zero-dependency, native JavaScript practice drill engine designed to take a student from absolute ground zero to full mastery of JavaScript language mechanics through **194 bite-sized, single-concept micro-lessons**.

---

## Key Features

- **Ground-Up Foundation**: Starts with the absolute basics (variables, functions, parameters, return values) before advancing to operators, expressions, memory models, objects, loops, recursion, string methods, functional programming, classes, and async workflows.
- **One Concept per Lesson**: Every challenge focuses on strictly one atomic rule or syntax pattern so you can code immediately without long reading sessions.
- **Ultra-Short READMEs (~20 lines)**: 1-sentence concept, clear syntax template, quick matching code example, and 1 clear practice task.
- **Zero-Dependency Native Suite**: Built on standard ECMAScript Modules (ESM) and Node.js native testing modules (`node:test`, `node:assert/strict`).
- **Interactive Practice Runner (`runner.js`)**: Step-by-step terminal drill engine with clean error highlighting that guides you through every challenge.
- **Instant Reset Engine (`reset.js`)**: Reset all challenge files to blank comment-only starter stubs at any time.
